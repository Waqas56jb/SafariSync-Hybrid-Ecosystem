# SafariSync-Hybrid-Ecosystem
SafariSync is a scalable hybrid ecosystem that combines a multilingual booking website, real-time web application, and AI-powered WhatsApp assistant into a unified platform. It features secure online payments, centralized booking management, photo-sharing workflows, and an advanced admin dashboard with cloud-ready architecture for future expansion.

## Client (React)

```bash
cd client
npm install
npm run dev
```

## Admin (React)

```bash
cd admin
npm install
npm run dev
```

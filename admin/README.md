# Vista Azul Admin (React)

Admin Control Deck — bookings, tours, gallery moderation, customers, WhatsApp bot, and settings.

## Setup

```bash
cd admin
npm install
npm run dev
```

Demo login: any email/password (prefilled `admin@vistaazul.co` / `admin123`).

## Scripts

- `npm run dev` — development server
- `npm run build` — production build
- `npm run preview` — preview production build
